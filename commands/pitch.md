# /catalyst:pitch

Determine mode from `catalyst_state.json` if present. Read `rollout_plan_FINAL.md` in simulation mode, or `ROLLOUT_PLAN.md` in advisory mode. If mode is unknown and exactly one of those files exists, use that file; if both exist, ask which plan to pitch from and stop; if neither exists, stop and point the user to `/catalyst:plan` (advisory) or the simulation template. In simulation only, if the final gate hasn't passed yet, note it — the pitch is stronger after the full panel signs off — but don't block.

Draft talking points for a **3-minute verbal pitch, presented from the plan doc — no new slides**. It must land these five beats, in order. In simulation mode these are exactly the five fields Mission Control asks for at The Final Pitch, in the same order — write each beat so it can be pasted into its field as well as spoken:

1. **Who goes first** — the opening move and the single data-backed reason. One paragraph the chair could repeat from memory.
2. **What gets funded** — the final allocation in brief: the biggest lines, the sharpest cut, the total inside the prevailing envelope. Must be consistent with every earlier commitment.
3. **How critical systems are protected** — the controls story in plain board language: validation, attestation, logs, reporting — who owns each, and what it gates.
4. **What success looks like** — Month-3 and Month-6, in numbers the CFO can falsify. Adoption, improvement, incidents, and the Year-2 setup.
5. **What would change this strategy again** — the named trigger(s) and the pre-committed response. Not "we'll stay agile."

Beat 5 is the one tables forget, and it's the one that separates a plan from a posture. A trigger without a pre-committed response doesn't count.

If the run absorbed curveballs, work that into beats 2–4 where it belongs — the regulator's letter into the controls story, the revised envelope into the allocation — rather than as a separate beat. What the board wants is the plan as it now stands, not a tour of how it changed.

Format: a spoken-word script with time marks (0:00 / 0:40 / 1:20 / 2:00 / 2:35), short sentences, numbers rounded for the ear ("about five thousand", not "4,946"). Close with one line the presenter can end on with confidence.

Then prep them for Q&A — list the three hardest questions this specific plan invites (read it critically: the soft budget line, the optimistic target, the hand-waved risk), each with a one-line honest answer.
