# Developer Sentiment Survey — AI Coding Tools

**n = 6,412 respondents** (64% response rate) · Conducted 4 weeks pre-Catalyst

## Headline

| Sentiment | % | n |
|---|---|---|
| **Excited** — "want it now" | 38% | 2,437 |
| **Cautious** — "interested but have questions" | 41% | 2,629 |
| **Concerned** — "skeptical or worried" | 21% | 1,346 |

## By division

| Division | Excited | Cautious | Concerned |
|---|---|---|---|
| Platform & DevEx | 61% | 32% | 7% |
| Retail & Digital Banking | 47% | 39% | 14% |
| Risk & Compliance Tech | 31% | 44% | 25% |
| Investment Banking Tech | 29% | 43% | 28% |
| Core Banking & Payments | 24% | 42% | 34% |

## By seniority

| Level | Excited | Cautious | Concerned |
|---|---|---|---|
| Junior | 52% | 33% | 15% |
| Mid | 41% | 41% | 18% |
| Senior | 33% | 44% | 23% |
| Staff / Principal | 27% | 42% | 31% |

## Top concerns (free-text, coded)

1. **Code quality / hallucinated APIs** — 43% of Concerned
2. **Job security / de-skilling of juniors** — 38%
3. **IP leakage / where does our code go** — 34%
4. **"Another tool mandate from leadership"** — 29%
5. **Doesn't understand our legacy systems** — 27% (heavily Core Banking)

## Selected verbatims

> "I've used it on side projects. It's genuinely great. I don't trust it near the matching engine." — Senior, IB Tech, London

> "If this is how leadership thinks they'll cut headcount, just say so." — Mid, Core Banking, Pune

> "Our COBOL estate isn't on Stack Overflow. What's it going to learn from?" — Staff, Core Banking, Dublin

> "The pilot team loved it but they're building React apps. Try it on a Basel calc and get back to me." — Principal, Risk Tech, Singapore

> "Honestly the best pair I've had in years. Ship it." — Senior, Digital Banking, Charlotte (pilot participant)

> "I'll use it if my manager doesn't see my prompt logs." — Junior, Retail, Mumbai

## What would make you more comfortable? (Cautious + Concerned, select-all)

- Clear policy on what code can/can't be sent — 67%
- Proof it works on *our* codebase, not demos — 58%
- Opt-in, not mandated — 51%
- Training that's more than a 30-min video — 44%
- Senior engineers I trust vouching for it — 41%
