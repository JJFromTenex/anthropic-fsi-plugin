# Project Catalyst Portal

The hosted participant, market, and instructor experience for the Project Catalyst FSI executive simulation.

## Experience

- Participants enter a workshop code and create or join a fictional bank.
- Every stage presents one decision, the available evidence, and three or four claimable ways to contribute.
- Attendees investigate alone or in pairs, add sourced findings, and reconvene around one shared decision.
- The instructor advances stages, releases progressive hints, and introduces the sector-wide alert.
- The shared market shows progress and milestone updates without turning the workshop into an arcade game.

## Development

```bash
npm install
npm run dev
npm test
```

D1 stores workshops, teams, stage contributions, findings, decisions, and market events.
